# specs/ui-states.md — UI & Mina states

## Modes
- **Parent mode:** calm, efficient, text-supported; clear status + privacy controls; restrained animation; utility-first review/edit.
- **Child mode:** full illustrated scene; ONE primary action per screen; large visual choices; minimal text; audio instructions; stable control positions; no settings/feeds/links.
- **Family mode:** one prompt at a time; one big play/replay button; confident vs learning-parent variants.

## Child interaction standards (hard)
- Min primary touch target 56×56 px · max 3 visible choices · max one short instruction sentence
- No typing · no hidden gestures · replay always available · mic state visually obvious
- Every audio instruction has a visual equivalent · works from 320px width
- Tamil / Simplified Chinese / Malay render without clipping
- Leaving child mode requires an adult press-and-hold gesture

## Mina states (mascot has a job — not decorative)
Welcome (wave) · Listening (wing by ear = mic active) · Thinking (looking up = processing) · Help (phrase card = replay/pronunciation) · Mission (points away = off-screen) · Handoff (offers token = give turn to family) · Celebrate (wings open) · Rest (sleeping = session ended).

## Brand
Charcoal-blue (text/trust) · sunflower yellow (energy/Mina) · teal (guidance/active) · coral (child interaction) · soft mint (calm bg). **Avoid purple.** Classic-premium feel.

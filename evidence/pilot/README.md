# Pilot — how to run a session

> **Requirement:** `specs/acceptance.md` → *Pilot (≥3 consented parent-child sessions)*
> **Submission checklist:** `docs/PRD.md` §29 → *Three pilot sessions completed with consent*

Three parent-child pairs, about 20 minutes each. You are **observing**, not
demonstrating. The point is to find where a real child hesitates — a session
where nothing goes wrong teaches us nothing and reads as staged to a judge.

## Before you start

1. **Consent.** Read `CONSENT.md` aloud to the parent and tick the boxes with
   them. No child faces are recorded. No child audio leaves the device.
2. Open **app.talelah.com**, sign in, and make sure the child's profile has
   the right home language — the story language follows it.
3. Have `session-template.md` open, copied to `session-1.md` (or 2 / 3).
4. Put your phone away. Watch the child, not the screen.

## Rules while observing

- **Do not coach.** If the child looks stuck, wait. The hesitation *is* the
  finding. Only step in after ~15 seconds, and write down that you did.
- **Do not fix the app.** If something breaks, note it and carry on.
- **Say nothing about what the app "should" do.** Let the parent discover it.
- Write the parent's words **verbatim**, including the unflattering ones.

## What we record — and nothing else

From `specs/acceptance.md`:

| # | Observation |
|---|---|
| 1 | Where does the child hesitate? |
| 2 | Are the controls understandable? |
| 3 | **Did the child speak?** |
| 4 | **Did they leave the screen for the mission?** |
| 5 | **Did the handoff happen?** |
| 6 | Parent comments |

Items 3, 4 and 5 are the golden path — capture → approve → child chooses →
child speaks → off-screen mission → family handoff → save memory. They are
the only yes/no answers that matter for the submission.

**No scores. No proficiency labels. No "behind" judgments** — that is a hard
product rule (`docs/PRD.md` FR-035) and it applies to our own notes too.

## Afterwards

Fill in `SUMMARY.md`. Three sessions is a sample, not a study — write what
happened, including what failed. One honest failure is worth more to a judge
than three clean runs.

## Files

| File | Purpose |
|---|---|
| `CONSENT.md` | Read to the parent, ticked before starting |
| `session-template.md` | Copy to `session-1/2/3.md` and fill during the session |
| `SUMMARY.md` | Aggregate after all three — this is the file judges read |
